# Robotyczno - Agentyczna Wykreślanka

Gra 11 × 11 z 10 pojęciami z robotyzacji. Działa w przeglądarce, bez serwera aplikacyjnego i bez instalacji.

Docelowy adres GitHub Pages: https://pawjan88.github.io/robotyczna-wykreslanka/

## Publikacja

Settings → Pages → Deploy from a branch → main → / (root) → Save.

Plik `kod-qr-brand.png` prowadzi do powyższego adresu. Zacznie prowadzić do gry po włączeniu i zakończeniu publikacji GitHub Pages.

## Hasła

ROBOT, PROCES, ROBOTYZACJA, EFEKTYWNOŚĆ, ALGORYTM, Agent AI, Prompt, LLM, Asystent, AUTONOMIA.

Na planszy hasła są zapisane wielkimi literami, bez spacji (Agent AI → AGENTAI).

Kierunki: w prawo, w dół, po skosie w dół i w prawo.

## Wygląd

Grafiki i kolory pochodzą z zatwierdzonych materiałów projektu. Czcionka: lokalny PKO Font 2024, a przy jego braku Arial lub systemowa bezszeryfowa.
